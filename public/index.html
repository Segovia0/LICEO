Mantenimiento de Datos y Respaldos

Garantice la integridad y seguridad del expediente escolar realizando respaldos periódicos del sistema.

Respaldo Local📥

Descargue directamente el archivo físico .sqlite a su computador.

Respaldo Completo📦

Descargue la base de datos junto con todas las fotografías en un solo archivo .tar.gz.

Respaldo en la Nube (Google Drive)☁️

Sube una copia con fecha de la base de datos al repositorio institucional de Google Drive.

Restaurar Sistema⚠️

Seleccione un respaldo .sqlite, .db o completo .tar.gz. Se reemplazarán los datos actuales y, si el archivo es completo, también las fotografías.
